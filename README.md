### Basic Headphone Stand

---
This is a Basic Headphone Stand, it features a headphone and phone stand.

## Features

- Standard phone and headphone mount
- Cut for phone camera bump
- Fits varies headphone and phone sizes
- Curved top part for headphone retention
- Tilted front part for phone retention
